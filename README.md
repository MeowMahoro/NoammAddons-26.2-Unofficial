## How to install?

1. Install **[Fabric for Minecraft 26.2](https://fabricmc.net/use/installer/)**
2. Install **[Fabric API](https://modrinth.com/mod/fabric-api/versions?g=26.2)** and **[Fabric Kotlin Language](https://modrinth.com/mod/fabric-language-kotlin)**
3. Download the latest mod file from the [**Releases page**](https://github.com/Noamm9/NoammAddons/releases)
4. Put the downloaded `.jar` files into your `.minecraft/mods` folder
5. Launch Minecraft using the **Fabric** profile

* Type  `/na` in chat to open the config menu.
